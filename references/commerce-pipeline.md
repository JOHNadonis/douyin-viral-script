# 带货口播稿 · 产线流程

用真实的成交文案当模板，不是凭空编。

句式库来自 **722 条真实转写文案**（东方满载 376 条 + 东方路 349 条，2026-10 抓取），已结构化到 `assets/structures.json`：36 个句式原型，覆盖开口 / 痛点 / 卖点 / 背书 / 价格 / 收尾六个位置，每个都带真实原文例句。

---

## 第 0 步：先确认品类，这是选词的起点

同样叫带货脚本，卖给谁决定怎么写。库里记录的是**食品/日用家庭采购**这一路（牛奶、鸡蛋、牛肉、水果、烘焙为主）。写**女性个人品类**（女装、美妆、内衣、饰品）要切换成另一套：

| 维度 | 家庭采购向（本库数据） | 女性个人向 |
|---|---|---|
| 称呼 | 孩子 333 次、我们 307 次、家人 56 次 | 姐妹为主（8 条样本中 6 条用） |
| 开头 | 「我说清楚」「我家常备」这类叙述 | 「天哪」「说真的」情绪感叹 |
| 中段重心 | 口感 + 质检 + 数字含量 | 设计细节 + 上身体验 + 场景覆盖 |
| 价格 | 到手数量、日均摊薄（养家算账） | 对比锚定、买赠（犒赏自己） |
| 结尾 | 小黄车 + 官网发货 + 保障 | 人群限定 +「冲/试试」轻行动词 |

**这不是谁对谁错，是受众不同。** 库里 36 个句式原型本身通用，只是填写时的用词、语气、称呼要跟着品类切。完整对照见 `corpus-findings.md` 第七节。

写女装/美妆/内衣时**优先参考 `混剪带货文案结构分析.md`**（女性品类样本，8 条），特别是第四节讲的「对比冲击」三种手法（夸张结果型 / 社交误解型 / 权威抢购型）——那是本库没有的技术，别因为样本少就低估它。

## 核心原则

1. **六个位置全填满。** 开口、痛点、卖点、背书、价格、收尾，缺一个脚本就松散。
2. **卖点必须有数字或具体物。** 「很好用」是废话，「通过 180 项质检」「蛋白质 4.0」才是卖点。
3. **收尾跟着品类走。** 食品/日用这类家庭采购品，结尾用「左下角小黄车，XXX发货，品质有保障」（语料里 64% 都这么收）；女装/美妆这类女性个人品，改成人群限定 +「冲/试试」，硬套小黄车句式会显得像硬广。
4. **字数卡在骨架区间。** 60 秒版 280-330 字，别写超，超了配音就赶。
5. **口语，不是文案。** 写完念一遍，念着别扭的地方就是该改的地方。

## 第 1 步：提取产品卡

```json
{
  "产品名": "低脂牛肉丸",
  "到手价": "75（原95）",
  "规格": "250g/包 送沙茶酱蒜蓉",
  "核心卖点": ["不添加牛油", "一粒23大卡", "淀粉＜1%", "有真牛肉味"],
  "数字支撑": ["180多项质检", "含肉量高于普通牛肉酱"],
  "产地原料": "巴西进口保乐肩/潮汕工艺",
  "适用人群": ["减脂党", "健身党", "有孩子的家庭"],
  "使用场景": ["火锅", "煮面", "水煮菜", "煎着吃"],
  "买家原话": ["一口一个巨满足 很有嚼劲 没怪味"]
}
```

**买家原话优先从评价区抄**，那不是编出来的话，转化力最强。

## 第 2 步：选骨架、导出段落安排

```bash
cd <skill目录>
python scripts/dvt.py plan --skeleton K1 --product "产品名" --seed 42 --out /path/plan.json
```

- `K1` 标准 60 秒（280-330 字）— 默认，语料主流形态
- `K2` 短版 30 秒（140-180 字）— 单卖点强打，测素材用
- `K3` 长版 90 秒（420-480 字）— 多卖点多背书，详情型产品

`--seed` 固定可复现；换 seed 就是换一套段落组合。要指定某几个句式：`--prefer O3,S2,C1`。

看全部句式：`python scripts/dvt.py list`
看单个句式：`python scripts/dvt.py show --id S2`

---

## 第 3 步：写脚本

按 plan.json 里的段落顺序，把每个 template 的槽位填上产品信息。槽位用 `[S]`（感官）`[T]`（信任）`[N]`（数字）表示。

产出格式：

```json
{"rows": [
  {
    "version": "K1-01",
    "opener": "O2 反问挑战",
    "pain": "P3 痛点堆叠",
    "sell": "S2质检+S3数字",
    "trust": "T2 产地溯源",
    "price": "R1 门槛弱化",
    "cta": "C1 标准收尾",
    "text": "完整脚本正文……"
  }
]}
```

写的时候看 `examples` 学语气——那些是真实成交文案的原句，照着那个说话方式写。

---

## 第 4 步：校验

```bash
python scripts/dvt.py check --scripts /path/filled.json --range 280-330 --require-cta --strict
```

查三件事：字数是否在区间、有没有促单句、有没有产品词。

---

## 第 5 步：装配

```bash
python scripts/dvt.py assemble --filled /path/filled.json \
  --out /path/产品名_带货脚本_N条.xlsx \
  --product-card /path/card.json
```

主表列：序号 / 版本 / 开口钩子 / 痛点切入 / 主打卖点 / 信任背书 / 价格处理 / 结尾方式 / 字数 / 脚本正文。
第二个 sheet 是产品信息卡。

最后用 `present_files` 交付。

---

## 批量出多版本

同一个产品要 N 条不重复的脚本，每个 seed 给一套不同的段落组合，分别填：

```bash
for s in 1 7 13 21 34 55; do
  python scripts/dvt.py plan --skeleton K1 --seed $s --out /tmp/plan_$s.json
done
```

结构同质、内容差异化。

## 各位置怎么写

见 `section-guide.md`（六位置逐个拆解 + 自检八问）。速查：

| 位置 | 必做 | 别做 |
|---|---|---|
| 开口 | 第一句就有信息量或冲突 | "大家好我是XX" |
| 痛点 | 说出具体画面（"又爱出汗还黏了吧唧"） | "你可能觉得不舒服" |
| 卖点 | 数字 + 专有名词 + 利益转化 | 只堆形容词 |
| 背书 | 报关单/检疫证/回购记录 | 空洞的"大品牌" |
| 价格 | 模糊化 + 到手数量 + 日均摊薄 | 报精确价格 |
| 收尾 | 固定句式 + 人群限定 | "购买""下单"这种硬词 |
