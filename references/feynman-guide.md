# 费曼学习法口播规范

**这份文档管的是知识类、AI 类口播稿。带货脚本走 `section-guide.md`，但带货稿可以借用费曼的讲解手法——见文末「费曼 × 带货融合」。**

## 为什么必须用费曼

AI 类内容有个反直觉的坑：**观众理解得越快，越容易划走。**

因为「听懂了」和「想继续听」是两件事。你三句话把结论给完了，观众得到的是「哦，知道了」，这个满足感一秒就闭合了，手就开始上滑。而带货不一样——带货的目的就是让他尽快知道产品好在哪然后下单，快是对的。知识内容不能快，快了就留不住。

费曼学习法的价值就在这：它不是"讲得简单"，而是**逼你把机制讲通**。观众跟着你走一遍因果链，中途有「哦原来是这样」的小顿悟，那个顿悟是密度型的满足感，会让他想继续。

**一句话原则：不要讲「是什么」，要讲「为什么会这样」。结论留不住人，因果链能留。**

## 五段结构（严格按顺序）

### 1️⃣ 钩子（前 3 秒，约 15 字）

四选一，不许混用，不许拖沓。

| 类型 | 机制 | 例子 |
|---|---|---|
| **反问** | 问出他正在疑惑的 | 「AI 到底是怎么看懂一张图的？」 |
| **反常识** | 先给反的判断 | 「AI 不是在思考，它是在做一道巨大的填空题。」 |
| **数字** | 反直觉的量 | 「1750 亿个参数，但它连你中午吃了什么都不知道。」 |
| **冲突** | 两个矛盾事实并置 | 「它能写论文，却算不对 13 乘 17。」 |

**禁止**：自我介绍、「今天我们来聊聊」、「最近有个话题很火」。

选哪个看主题：
- 机制类（原理、为什么）→ 反常识
- 现象类（大家都在用但不懂）→ 冲突
- 数字类（参数、成本、速度）→ 数字
- 困惑类（我怎么老用不好）→ 反问

### 2️⃣ 痛点共鸣（3-12 秒，40-60 字）

**说出观众心里正在想的那句话，不是你想让他想的话。**

- 弱：很多人对 AI 有误解
- 强：你问它一个问题，它答得头头是道，你照着做发现全是错的，然后就再也不敢信它了

- 弱：提示词很重要
- 强：同一个问题，别人问出来的答案就是比你好。你怀疑是工具不行，其实是问法不一样，但你就是说不清差在哪

要点：讲**处境**，不讲道理。用「你」不用「大家」。

### 3️⃣ 本期承诺（12-20 秒，25-40 字）

明确告诉他看完能得到什么。三种模板：

- 解决问题：「这期讲完，你就知道它为什么会编，也能一眼看出哪句是编的。」
- 学会方法：「看完你会知道怎么问，能让它答对率明显不一样。」
- 避开坑：「这里有个坑，我踩过，讲完你能绕过去。」

**禁止**：「很有用」「干货满满」「建议看完」。

> ⚠️ **带货稿里绝对不能用这一段的说法。** 「这期讲完」「本期」「今天讲」这类元叙述，一旦出现在卖货视频里，观众立刻意识到「他在给我上课」，广告感骤增，划走率上升。
>
> **带货稿的正确做法**：把承诺藏进痛点共鸣里，或者直接省略这一段，用产品本身当承诺。
> - ❌ 「这期讲完你就知道含氟量该看哪个数。」
> - ✅ 「这事其实有个区间，就像放盐……」（直接把答案给出去，不预告）
>
> 判断标准：**说出来的话，观众听着像不像一个人在现场跟你说话。** 「这期讲完」是节目语言，不是人话。

### 4️⃣ 正文·费曼讲解（20-70 秒，150-200 字）

这一段是全篇核心，**四件事必须都做**：

#### A. 一个贴切的生活类比

类比必须**同构**——结构对得上，不是听起来像。

三步找类比：
1. 找出这个概念的**核心动作**是什么（它在做什么事？）
2. 在日常生活里找**做同一个动作**的事
3. 把这个事讲成一句话

好的类比：

| 概念 | 类比 | 为什么同构 |
|---|---|---|
| 大模型生成文字 | 玩接龙，一直猜下一个词最可能是啥 | 都是逐字推进、都靠概率、都不需要理解全局 |
| 向量 | 把词放到一张巨大的地图上，意思近的住得近 | 都是靠距离表示相似度 |
| 上下文窗口 | 一张桌子，桌子多大就能摊开多少纸 | 都有硬性容量上限，超了就得拿走 |
| 微调 | 已经会开车的人熟悉一辆新车 | 都不是从零学，是在已有能力上适配 |
| RAG | 回答前先翻资料，而不是凭记忆说 | 都是外部检索+再作答 |

坏的类比：

- 「AI 就像一个聪明的大脑」→ 听起来像类比，其实什么都没说明
- 「这就像量子力学一样复杂」→ 观众更懵
- 「就像人一样」→ 偷懒，人和 AI 的工作机制完全不同

#### B. 术语一出现就翻译

不要等观众去查。每出现一个专业词，当场用大白话翻掉。

句式：
- 「XX，说白了就是……」
- 「XX 这个词听着吓人，其实就是……」
- 「换句话说，……」

常用对照：

| 术语 | 翻译 |
|---|---|
| 参数 | 模型脑子里那些调好的旋钮，拧到某个位置就形成了它的「性格」 |
| 训练 | 给它看成千上万个例子，让它自己摸规律，没人告诉它答案 |
| 推理 | 你问一句，它现场算一遍再回答 |
| 上下文 | 它这次能记住的谈话内容，出了范围就忘 |
| 微调 | 已经学会的基础上，再针对某个领域补课 |
| 幻觉 | 不知道答案，但不愿说不知道，就编了个听起来很像的 |
| 提示词 | 你跟它说话的方式。说得好它做得对，说得糊它做得偏 |
| 向量 | 把文字变成一串数字，这样计算机才能比较两段话像不像 |
| RAG | 回答前先去翻资料，翻完再答 |

#### C. 主动纠正一个误解 ← 这一步最容易漏，也最加分

费曼学习法的精髓：**讲不通的地方，往往是你自己理解错了。** 主动拎出一个大众误解并纠正，可信度立刻上一个台阶，而且观众会有「原来我一直想错了」的顿悟感——这个顿悟就是留人的钩子。

句式：
- 「很多人以为……其实不是。……」
- 「这也是为什么……」
- 「你可能会以为……恰恰相反，……」

例子：
- 「很多人以为 AI 记住了你说的话，其实不是。它每次回答都是从零开始，只是把前面的对话又读了一遍。」
- 「很多人以为参数越多越聪明，其实不是。参数多只是脑容量大，用不用得上还得看怎么训练。」
- 「很多人以为它在搜索，其实不是。它是凭训练时记住的规律现场造句，所以才会一本正经地编。」

#### D. 节奏控制

写出来要像在说话，不是像在念稿。

- 长句讲机制，短句砸结论
- 每 3-4 句插一个短句（5-8 字）让人喘口气：「说白了就一句话：它在猜。」「就这么简单。」「不是它笨，是这活它本来就不擅长。」
- 避免书面语：不要「综上所述」「值得注意的是」「由此可见」
- 用口语连词：「但是」「所以」「其实」「你看」「你想啊」

### 5️⃣ 结尾 CTA（70-90 秒，20-35 字）

**顺着内容自然收尾，不要硬转。**

好的：
- 「下次它再答得头头是道，你就知道该多问一句：这个说法的依据是什么。关注我，下期讲怎么让它少编。」
- 「这个判断方法很简单，你可以收藏起来，下次用的时候翻出来对一遍。」
- 「如果你也踩过这个坑，评论区说一句，我看看有多少人一样。」

不好的：
- 「记得一键三连」（模板话）
- 「喜欢的话点个关注」（跟内容无关）
- 「下期更精彩」（空话）

## 平台差异

| 平台 | 钩子偏好 | 字数 | 注意 |
|---|---|---|---|
| 抖音 | 冲突 / 反常识 | 260-330（60-90秒） | 前 3 秒要冲击，每 10 秒一个信息点 |
| 视频号 | 反问 / 痛点共鸣 | 300-380（70-100秒） | 受众年龄偏大，类比用家庭/职场/健康场景，少用网络梗 |
| 小红书 | 数字 / 反常识 | 220-280（50-70秒） | 爱收藏，结尾引导收藏比点赞有效 |

## 自检清单

写完逐条过，一条不过就重写：

1. 钩子是不是四种之一？有没有自我介绍或「今天聊聊」？
2. 痛点那句，是不是观众心里原话？用「你」了吗？
3. 承诺具体吗？看完能得到什么说得清吗？
4. **有没有一个同构的类比？** 拿掉类比这段还成立吗（成立说明类比没用上）？
5. **每个术语都翻译了吗？** 有没有哪个词观众可能不认识但你没解释？
6. **有没有主动纠正一个误解？** 这是最容易漏的一条。
7. 念一遍，有没有卡壳的地方？
8. 结尾是不是顺着内容走的？还是硬贴了一句「点个关注」？
9. 字数在平台区间内吗？

## 一个完整示范（主题：大模型幻觉）

> **钩子类型：反常识**
>
> AI 不是在「思考」，它是在做一道超大的填空题。
>
> 你问它一个问题，它答得特别顺，还给你列了一二三四。你照着做，发现第一条就是错的。于是你开始怀疑：这东西到底能不能信？
>
> 这期讲完，你就知道它为什么会编，也能一眼看出哪句话是编的。
>
> 它的工作方式其实像玩接龙。你说一句，它猜下一个词最可能是啥，猜完再猜下一个，一路猜下去。它不知道这句话对不对，只知道「按前面这些字，接这个词最顺」。
>
> 所以当它不知道答案的时候，它不会停下来。因为接龙这个游戏没有「我不知道」这个选项，只有「下一个词最可能是什么」。于是它就编了一个最顺的。
>
> 很多人以为它在网上搜了一圈才回答，其实不是。它是在凭训练时记住的规律现场造句。搜了会有出处，造句没有。
>
> 下次它再答得头头是道，你就多问一句：这个说法的依据是什么。关注我，下期讲怎么问能让它少编。

# 费曼 × 带货融合（实测最有效）

费曼用在带货上，不是把带货拍成科普。正确做法是：**保留东方甄选那套卖货腔，只在「卖点讲解」这一段借用费曼四要素。**

## 三条铁律

### 1. 绝不出现元叙述

`这期讲完` `本期` `今天讲` `我们来聊聊` `看完你就知道` —— 全部禁用。

卖货视频里说这话，观众立刻感觉「他在给我上课」，广告感暴露，划走。

**替代做法**：不预告，直接把答案给出去。
- ❌ 「这期讲完你就知道含氟量该看哪个数。」
- ✅ 「这事其实有个区间，就像放盐，太少没味，太多齁得慌。」

### 2. 收尾必须回到东方甄选的固定句式

费曼知识稿的收尾是「关注我下期讲…」，带货稿不能这么收，会散掉。

**带货收尾唯一标准**：
> 喜欢的话，左下角小黄车，东方甄选官网发货，品质有保障。

四个要素不能缺：**喜欢的话**（语气软化）/ **左下角小黄车**（动线）/ **官网发货**（信任）/ **品质有保障**（兜底）。

只用「左下角小黄车，官网发货，品质有保障」是简化版，会少一点烟火气。「喜欢的话」这四个字是东方甄选味道的关键——它是商量，不是命令。

### 3. 数字后面必须跟一句「这意味着什么」

原文案的通病是数字罗列：`含氟0.1%、馅含量80%、电解质520mg`。观众听完整理不出来。

| 只报数字 | 数字 + 机制 |
|---|---|
| 纸皮烧麦馅含量80%以上 | 咬开基本全是馅，不是一层面皮包一点肉 |
| 检测报告支持12小时防蛀 | 它在牙面上留一层慢慢释放，不是刷完就没了 |
| 常温能存12个月 | 靠超高温灭菌加低温灌装，先把菌杀掉再封起来 |
| 油酸占脂肪酸75%以上 | 它稳，不容易跟空气起反应，说白了就是不容易散架 |

## 可以保留的「东方甄选味道」

这几句是品牌资产，别为了「原创」把它们改掉：

- 「这些数不是宣传话术，是配料表上能对的。」
- 「都是东方甄选自营的品」
- 「开盖记得密封，不然就不脆了」（生活提醒，显真实）
- 「刷完记得吐掉别吞」（使用叮嘱，显负责）
- 「冰过更好喝」「家里常备」（场景延长）
- 「我家已经回购三次了」（自用背书）

**别怕和商品原文案有几句相似。** 品牌话术本来就该稳定复现，观众认的就是这个调子。真正要避免的是整段照搬。

## 融合版结构

```
钩子（可以是痛点/冲突/赌约，不必强行反常识）
  ↓
痛点共鸣（一句到两句，说处境）
  ↓
卖点讲解【费曼区】← 只有这一段用费曼
  ├ 类比（一个，同构）
  ├ 数字 + 机制翻译
  ├ 纠误解（一句「很多人以为…其实不是」）
  └ 节奏（短句插在长句后）
  ↓
价格（门槛弱化 / 到手数量 / 日均摊薄）
  ↓
固定收尾（喜欢的话，左下角小黄车，东方甄选官网发货，品质有保障）
```

## 实测效果

4 篇融合版 vs 商品原文案：

| 指标 | 数值 |
|---|---|
| 字数 | 306-330（原 161-212） |
| 逐句 ≥75% 相似 | 0 条 |
| 纯措辞重复率 | 极低（数字和术语剔除后） |
| 费曼三要素 | 4/4 全覆盖 |
| 东方甄选收尾四要素 | 4/4 全覆盖 |
| 元叙述 | 0 处 |

结构和味道都在。这版可作标准。
